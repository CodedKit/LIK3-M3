# **App Name**: Virtual Temptations

## Core Features:

- Logo/Boot Screen: Display animated loading bar with percentage progress, duration 3 seconds and a smooth fade-in/out animation.
- Account Creation: Enable avatar selection, username input with validation, and account creation confirmation.
- Desktop Environment: Implement an interactive desktop environment with a customizable icon grid and responsive UI.
- Menu Bar: Create a functional menu bar with 'Start' button (account info, settings) and system status indicators (time, Wi-Fi, battery, audio).
- Application Interactions: Build the shell for the interactive applications such as Likestagram and Terminal with basic functionalities.
- Profile Persistence: Save and retrieve user profiles locally to ensure returning users retain their account.

## Style Guidelines:

- Primary color: Dark purple (#4A148C) to evoke a sense of mystery and sophistication.
- Background color: Very dark gray (#121212), almost black, complements the dark purple while reducing eye strain in long sessions.
- Accent color: Deep pink (#D81B60), a vibrant color that stands out against the dark scheme, for interactive elements and notifications.
- Headline font: 'Poppins', sans-serif, with its geometric and modern style suitable for UI headings.
- Body font: 'Inter', sans-serif, known for its readability and clean design, optimal for in-app descriptions and content.
- Code font: 'Source Code Pro' for the Terminal application.
- Smooth transitions and loading animations using Framer Motion to enhance user experience and engagement.
